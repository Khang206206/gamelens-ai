3. QUYET DINH KY THUAT DE XUAT
-----------------------------

3.1 Runtime va dependency

- Target Python 3.12 de uu tien do tuong thich cua FastAPI/SQLAlchemy.
- Dinh nghia project va tool configuration trong apps/api/pyproject.toml.
- Pin exact dependency versions luc implementation, sau compatibility test.
- Runtime dependencies toi thieu:
  FastAPI, Uvicorn, Pydantic Settings, SQLAlchemy 2.x, Psycopg 3 va Alembic.
- Development dependencies toi thieu:
  pytest, pytest-cov, HTTPX va Ruff.
- Chua dua mypy vao Stage 1 neu no lam tang setup ma chua tao gia tri ro rang.

3.2 Database access

- Dung SQLAlchemy 2.x synchronous session cho MVP.
- Khong dung async database stack o Stage 1; no tang do phuc tap ma catalog
  nho chua duoc loi ro rang.
- PostgreSQL 16 tiep tuc la database chinh.
- SQLite in-memory chi phuc vu test nhanh, khong quyet dinh schema production.
- Migration phai duoc test rieng tren PostgreSQL that.

3.3 Layering

Luon giu luong:

route -> service -> repository -> SQLAlchemy session -> PostgreSQL

- Route: HTTP parsing, dependency injection va response schema.
- Service: use case, rule va error domain.
- Repository: query va persistence.
- Schema: Pydantic request/response contract.
- Model: SQLAlchemy mapping, khong tra truc tiep ra API.

3.4 Configuration va security

- Tat ca setting den tu environment variables.
- CORS la allowlist, khong dung wildcard khi credentials duoc bat.
- Khong log password, DATABASE_URL day du hoac secret.
- UTC va timezone-aware timestamp.
- Request validation va error envelope nhat quan.
- Seed data khong chua cover image co ban quyen.

3.5 Recommendation boundary

- Tao interface/abstract contract cho recommendation service.
- Model status endpoint phai noi ro "not configured" den Stage 3.
- Khong tao stub tra ve score/recommendation gia.
- Khong train model trong API request.
